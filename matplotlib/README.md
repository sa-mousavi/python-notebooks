# کدهای آموزشی  (Matplotlib)

این مخزن شامل کدهای پیاده‌سازی شده برای کتابچه آموزشی **Matplotlib** است. تمام مثال‌ها با رویکرد شیءگرا (Object-Oriented) و با هماهنگی کامل با بسته‌های LaTeX نوشته شده‌اند تا کیفیت خروجی نمودارها برای چاپ در کتابچه بهینه باشد.

## ساختار فایل‌ها
کدها بر اساس نوع نمودار طبقه‌بندی شده‌اند:

- **`matplotlib/01_pie_charts/`**: شامل کدهای مربوط به نمودارهای دایره‌ای و دونات.
- **`matplotlib/02_bar_charts/`**: شامل نمودارهای میله‌ای ساده، چندسری و پشته‌ای.

## راهنمای استفاده
برای اجرای هر کدام از کدها، کافی است فایل `.py` مورد نظر را دانلود کرده و در محیط پایتون خود اجرا کنید. مطمئن شوید که کتابخانه‌های `numpy` و `matplotlib` نصب شده باشند.
